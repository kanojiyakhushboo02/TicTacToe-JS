

# Tic-Tac-Toe Game 🎮

A simple and interactive Tic-Tac-Toe game built using **HTML**, **CSS**, and **JavaScript**. The game supports two players and announces the winner when three marks align horizontally, vertically, or diagonally. Includes a reset and new game functionality for seamless gameplay.

## 🛠️ Features

- **Two-Player Gameplay**: Alternate turns between Player X and Player O.
- **Winner Announcement**: Highlights the winner when three marks align.
- **Draw Detection**: Alerts players if the game ends in a draw.
- **Responsive Design**: Fully functional on desktop and mobile devices.
- **Easy Reset**: Start a new game with a single click.

## 🕹️ How to Play

1. **Start the Game**: Player O always starts first.
2. **Take Turns**: Click on an empty box to place your mark (O or X).
3. **Win the Game**: Align three of your marks horizontally, vertically, or diagonally.
4. **Draw**: If all boxes are filled without a winner, the game ends in a draw.
5. **Reset or New Game**: Click the "Reset Game" or "New Game" button to play again.
